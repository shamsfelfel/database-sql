Chapter 3 test

اختبار الفصل الثالث

Twenty questions across all six lessons. This test builds two related tables as you go — advisors and students (with an advisor_id foreign key) — then joins, updates, and deletes across them. Each write-statement question is graded as if the earlier ones were answered correctly, so answer them in order.

عشرون سؤالًا تغطي الدروس الستة جميعها. يبني هذا الاختبار جدولين مترابطين أثناء تقدّمك — advisors وstudents (بمفتاح أجنبي advisor_id) — ثم يربط بينهما ويحدّث ويحذف عبرهما. ويُصحَّح كل سؤال كتابة عبارة كأن الأسئلة السابقة أُجيبت بشكل صحيح، لذا أجِبها بالترتيب.

1write statement

Create a table named advisors with: id (integer primary key), name (text).

أنشئ جدولًا اسمه advisors يحتوي: id (مفتاح أساسي صحيح)، name (نص).

2write statement

Insert three advisors into advisors: (1, 'Dr. Nour Aziz'), (2, 'Dr. Peter Lindqvist'), (3, 'Dr. Sana Okafor').

أدرج ثلاثة مرشدين في advisors: (1, 'Dr. Nour Aziz') و(2, 'Dr. Peter Lindqvist') و(3, 'Dr. Sana Okafor').

5write statement

Create a table named students with: id (integer primary key), name (text), gpa (real), advisor_id (integer).

أنشئ جدولًا اسمه students يحتوي: id (مفتاح أساسي صحيح)، name (نص)، gpa (عدد حقيقي)، advisor_id (عدد صحيح).

6write statement

Insert four students into students: (1, 'Yara Haddad', 3.7, 1), (2, 'Ben Torres', 3.2, 1), (3, 'Mei Lin', 3.9, 2), (4, 'Omar Farouk', 3.4, 3).

أدرج أربعة طلاب في students: (1, 'Yara Haddad', 3.7, 1) و(2, 'Ben Torres', 3.2, 1) و(3, 'Mei Lin', 3.9, 2) و(4, 'Omar Farouk', 3.4, 3).

8write statement

Select each student's name and their advisor's name (aliased as advisor_name), joining students to advisors.

اختر name كل طالب وname مرشده (باسم مستعار advisor_name)، بربط students بـ advisors.

11write statement

Select the name of every student whose gpa is greater than 3.5, along with their advisor's name (aliased as advisor_name).

اختر name كل طالب gpaه أكبر من 3.5، مع name مرشده (باسم مستعار advisor_name).

13write statement

Add 0.1 to the gpa of every student advised by 'Dr. Peter Lindqvist'.

أضِف 0.1 إلى gpa كل طالب يرشده 'Dr. Peter Lindqvist'.

16write statement

Delete every student advised by 'Dr. Sana Okafor' with gpa below 3.5.

احذف كل طالب يرشده 'Dr. Sana Okafor' ومعدّله gpa أقل من 3.5.

17write statement

Re-point the student with id 2 to advisor id 3.

أعِد توجيه الطالب ذي id 2 إلى المرشد ذي id 3.

20write statement

Remove the advisor_id column from students entirely.

أزِل عمود advisor_id من students بالكامل.
