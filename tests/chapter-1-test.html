Chapter 1 test

اختبار الفصل الأول

Twenty questions across all five statements. Most of this test builds up a brand-new clubs table as you go — each write-statement question is graded as if the earlier ones were answered correctly, so answer them in order. The Database panel shows clubs taking shape.

عشرون سؤالًا تغطي العبارات الخمس جميعها. يبني معظم هذا الاختبار جدولًا جديدًا اسمه clubs أثناء تقدّمك — ويُصحَّح كل سؤال كتابة عبارة كأن الأسئلة السابقة أُجيبت بشكل صحيح، لذا أجِبها بالترتيب. وتُظهر لوحة قاعدة البيانات جدول clubs وهو يتشكّل.

1write statement

Create a table named clubs with an integer primary key id and a text column name.

أنشئ جدولًا اسمه clubs بمفتاح أساسي صحيح id وعمود نصّي name.

5write statement

Insert three clubs into clubs: (1, 'Chess Club'), (2, 'Robotics Club'), (3, 'Debate Club'), in one statement.

أدرج ثلاثة نوادٍ في clubs: (1, 'Chess Club') و(2, 'Robotics Club') و(3, 'Debate Club')، في عبارة واحدة.

9write statement

Select every row from clubs.

اختر كل صف من clubs.

10write statement

Select just the name column from clubs, for the club with id 2.

اختر عمود name فقط من clubs، للنادي ذي id 2.

14write statement

Rename the club with id 3 to 'Debate & Public Speaking Club'.

أعِد تسمية النادي ذي id 3 إلى 'Debate & Public Speaking Club'.

18write statement

Delete the club with id 1.

احذف النادي ذا id 1.
