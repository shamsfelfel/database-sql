Chapter 6 test

اختبار الفصل السادس

Twenty independent questions across all three databases — CREATE VIEW, reading and filtering views, views over a JOIN and over GROUP BY, views built on views, redefining a view, and DROP VIEW. Each write-statement question is graded on what your statement actually produces, so any correct answer passes. Use the exact view and column names each prompt asks for.

عشرون سؤالًا مستقلًّا عبر القواعد الثلاث جميعها — CREATE VIEW والقراءة من العروض وتصفيتها، والعروض على JOIN وعلى GROUP BY، والعروض المبنيّة على عروض، وإعادة تعريف العرض، وDROP VIEW. ويُصحَّح كل سؤال كتابة عبارة بناءً على ما تُنتجه عبارتك فعلًا، فأيّ إجابة صحيحة تنجح. استعمل أسماء العروض والأعمدة التي يطلبها كل سؤال بالضبط.

2write statement

Create a view named cheap_books returning id, title and price for every book priced below 15.

أنشئ عرضًا باسم cheap_books يُعيد id وtitle وprice لكل كتاب سعره أقل من ١٥.

4write statement

Create a view named featured_names with exactly two columns — name and brand — covering the featured products only.

أنشئ عرضًا باسم featured_names بعمودين بالضبط — name وbrand — يغطّي المنتجات المميّزة فقط.

6write statement

Create a view named active_list with the columns title, credits and level, covering the active courses only.

أنشئ عرضًا باسم active_list بالأعمدة title وcredits وlevel، يغطّي المقرّرات النشِطة فقط.

7write statement

The view book_catalog (title, genre, price) already exists. Read from it and return the title of every Fantasy book.

العرض book_catalog (title وgenre وprice) موجود مسبقًا. اقرأ منه وأعِد title لكل كتاب من نوع Fantasy.

9write statement

Create a view named product_dept joining products to categories, with exactly two columns: product_name (the product's name) and department.

أنشئ عرضًا باسم product_dept يربط products بـcategories، بعمودين بالضبط: product_name (اسم المنتج) وdepartment.

10write statement

The joined view course_info (title, credits, department_name, building) already exists. Return the title of every course taught in Sciences Hall.

العرض المربوط course_info (title وcredits وdepartment_name وbuilding) موجود مسبقًا. أعِد title لكل مقرّر يُدرَّس في Sciences Hall.

11write statement

Create a view named genre_counts with one row per genre and two columns: genre and book_count.

أنشئ عرضًا باسم genre_counts بصفّ واحد لكل genre وعمودين: genre وbook_count.

13write statement

The summary view brand_stats (brand, product_count, total_stock) already exists. Return the brand of every brand with 2 or more products.

العرض الملخّص brand_stats (brand وproduct_count وtotal_stock) موجود مسبقًا. أعِد brand لكل علامة تجارية لها منتجان أو أكثر.

14write statement

Create a view named level_caps with one row per level and two columns: level and total_cap — the enrollment_cap values added up.

أنشئ عرضًا باسم level_caps بصفّ واحد لكل level وعمودين: level وtotal_cap — مجموع قيم enrollment_cap.

16write statement

The view recent_books (id, title, genre, price, published_year) exists. On top of it, create a view named recent_cheap with the columns title and price, keeping only books priced below 20.

العرض recent_books (id وtitle وgenre وprice وpublished_year) موجود. أنشئ فوقه عرضًا باسم recent_cheap بالعمودين title وprice، مع الإبقاء على ما سعره أقل من ٢٠ فقط.

17write statement

The view featured_products (id, name, price, category_id) exists. Join it to categories and return name and department for the featured products in the Electronics department. Use exactly those two column names.

العرض featured_products (id وname وprice وcategory_id) موجود. اربِطه بـcategories وأعِد name وdepartment للمنتجات المميّزة في قسم Electronics. استخدم هذين الاسمين بالضبط.

18write statement

The view old_report is no longer needed. Remove it, leaving departments and courses as the only objects in the database.

العرض old_report لم تبقَ حاجة إليه. احذفه، بحيث يبقى departments وcourses وحدهما في قاعدة البيانات.

19write statement

The view cheap_books (id, title, price) currently uses the threshold price < 15. Redefine it — same name, same columns — so the threshold becomes price < 25.

العرض cheap_books (id وtitle وprice) يستخدم حاليًا الحدّ price < 15. أعِد تعريفه — بالاسم نفسه والأعمدة نفسها — ليصبح الحدّ price < 25.

20write statement

Everything at once: create a view named dept_summary that joins products to categories and returns one row per department with three columns — department, product_count, and avg_price (the average price rounded to 2 decimals).

كل شيء معًا: أنشئ عرضًا باسم dept_summary يربط products بـcategories ويُعيد صفًّا واحدًا لكل department بثلاثة أعمدة — department وproduct_count وavg_price (متوسّط السعر مقرّبًا إلى منزلتين).
