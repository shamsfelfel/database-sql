Chapter 7 test

اختبار الفصل السابع

Twenty independent questions across all three databases — anomalies, first normal form, functional dependencies and 2NF, 3NF, and diagnosing a design. Some ask you to name a problem; others ask you to write the SQL that exposes it, tests a dependency, or reassembles the normalized tables. Each write-statement question is graded on what your statement actually produces, so any correct answer passes. Use the exact table and column names each prompt asks for.

عشرون سؤالًا مستقلًّا عبر القواعد الثلاث جميعها — الشذوذ، والنموذج الأول، والاعتمادات الوظيفية و2NF، و3NF، وتشخيص التصميم. بعضها يطلب منك تسمية المشكلة، وبعضها يطلب أن تكتب عبارة SQL تكشفها، أو تختبر اعتمادًا، أو تُعيد تجميع الجداول المُطبَّعة. ويُصحَّح كل سؤال كتابة عبارة بناءً على ما تُنتجه عبارتك فعلًا، فأيّ إجابة صحيحة تنجح. استعمل أسماء الجداول والأعمدة التي يطلبها كل سؤال بالضبط.

2write statement

Measure the redundancy in library_1nf: return one row per member_name with a column copies — how many rows repeat that member's details.

قِس التكرار في library_1nf: أعِد صفًّا واحدًا لكل member_name مع عمود copies — عدد الصفوف التي تكرّر بيانات ذلك العضو.

6write statement

In 1NF one condition is enough. Using orders_1nf, return the order_id of every order that contains Pulse Studio Headphones.

في النموذج الأول يكفي شرط واحد. باستعمال orders_1nf، أعِد order_id لكل طلب يحتوي Pulse Studio Headphones.

10write statement

Test the dependency author_name → author_country against the data: from library_1nf, return one row per author_name with a column country_versions — the number of different author_country values stored for that author.

اختبر الاعتماد author_name → author_country على البيانات: من library_1nf، أعِد صفًّا واحدًا لكل author_name مع عمود country_versions — عدد قيم author_country المختلفة المخزّنة لذلك المؤلف.

13write statement

Carve out the students part of a 2NF split: from enrollments_flat, return each student once, with the columns student_id, student_name and study_year.

اقتطع جزء الطلاب من تقسيم 2NF: من enrollments_flat، أعِد كل طالب مرة واحدة، بالأعمدة student_id وstudent_name وstudy_year.

16write statement

Normalization loses nothing: rebuild the loan sheet from the 3NF tables. Join loans, members, loan_items and books and return one row per borrowed book with three columns — loan_id, member_name and book_title.

التطبيع لا يُضيّع شيئًا: أعِد بناء سجلّ الإعارات من جداول 3NF. اربط loans وmembers وloan_items وbooks، وأعِد صفًّا لكل كتاب مُستعار بثلاثة أعمدة — loan_id وmember_name وbook_title.

17write statement

In 3NF a customer's email lives in one row. Hani Zorob (id 1) changes his email to 'hani.z@mail.ps': write the UPDATE on customers that records it — touching only his row.

في 3NF يسكن بريد الزبون صفًّا واحدًا. غيّر هاني زعرب (id ١) بريده إلى 'hani.z@mail.ps': اكتب عبارة UPDATE على customers تسجّل ذلك — دون أن تمسّ إلا صفّه.

18write statement

In the flat sheet a book could not exist until someone borrowed it. Now it can: return the title of every book in books that appears in no row of loan_items.

في الورقة المسطّحة لم يكن للكتاب وجود قبل أن يستعيره أحد. أما الآن فله: أعِد title لكل كتاب في books لا يظهر في أيّ صفّ من loan_items.

19write statement

Rebuild part of the registrar's sheet from the normalized tables: join enrollments, students, courses and departments, and return one row per enrollment with three columns — student_name, course_title and building.

أعِد بناء جزء من ورقة المسجّل من الجداول المُطبَّعة: اربط enrollments وstudents وcourses وdepartments، وأعِد صفًّا لكل تسجيل بثلاثة أعمدة — student_name وcourse_title وbuilding.
