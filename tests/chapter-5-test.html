Chapter 5 test

اختبار الفصل الخامس

Twenty independent questions across all three databases — COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING, and aggregation over a JOIN. Each write-statement question is graded on the rows it returns, so any correct query passes. Use the exact column names each prompt asks for.

عشرون سؤالًا مستقلًّا عبر القواعد الثلاث جميعها — COUNT وSUM وAVG وMIN وMAX وGROUP BY وHAVING والتجميع عبر JOIN. ويُصحَّح كل سؤال كتابة عبارة بناءً على الصفوف التي يُعيدها، فأيّ استعلام صحيح ينجح. استعمل أسماء الأعمدة التي يطلبها كل سؤال بالضبط.

2write statement

Count how many books there are in total. Return it as a column named book_count.

عُدَّ كم كتابًا يوجد إجمالًا. أعِده في عمود اسمه book_count.

4write statement

Add up the stock_qty of every product. Return the total as a column named total_stock.

اجمع stock_qty لكل منتج. أعِد المجموع في عمود اسمه total_stock.

6write statement

Return the average credits across all courses, rounded to 2 decimals, as a column named avg_credits.

أعِد متوسّط credits عبر كل المقررات، مقرّبًا إلى منزلتين، في عمود اسمه avg_credits.

7write statement

In one query, return the lowest and highest book price as columns named min_price and max_price.

في استعلام واحد، أعِد أدنى وأعلى سعر كتاب في عمودين اسمهما min_price وmax_price.

9write statement

For each category_id, return the category id and how many products it has. Use the columns category_id and product_count.

لكل category_id، أعِد رقم الفئة وعدد منتجاتها. استخدم العمودين category_id وproduct_count.

10write statement

For each level, return the level and how many courses have it. Use the columns level and course_count.

لكل level، أعِد المستوى وعدد المقررات فيه. استخدم العمودين level وcourse_count.

12write statement

Return each genre that has more than one book, with its book count. Use the columns genre and book_count.

أعِد كل genre فيه أكثر من كتاب، مع عدد كتبه. استخدم العمودين genre وbook_count.

14write statement

Return each brand that has 2 or more products, with its product count. Use the columns brand and product_count.

أعِد كل brand له منتجان أو أكثر، مع عدد منتجاته. استخدم العمودين brand وproduct_count.

15write statement

Join courses to departments and, for each department name, return the department and its course count. Use the columns department and course_count.

اربِط courses بـdepartments، ولكل name قسم أعِد القسم وعدد مقرّراته. استخدم العمودين department وcourse_count.

17write statement

Join books to authors and, for each author name, return the author and how many books they wrote. Use the columns author and book_count.

اربِط books بـauthors، ولكل name مؤلف أعِد المؤلف وعدد كتبه. استخدم العمودين author وbook_count.

18write statement

Join products to categories and, for each department, return the department and its average product price rounded to 2 decimals. Use the columns department and avg_price.

اربِط products بـcategories، ولكل department أعِد القسم ومتوسّط سعر منتجاته مقرّبًا إلى منزلتين. استخدم العمودين department وavg_price.

19write statement

Return the single highest enrollment_cap across all courses as a column named max_cap.

أعِد أعلى enrollment_cap واحد عبر كل المقررات في عمود اسمه max_cap.

20write statement

Combining a JOIN, a WHERE, a GROUP BY and a HAVING: among featured products only, join products to categories and return each department that has 2 or more featured products, with that count. Use the columns department and featured_count.

بجمع JOIN وWHERE وGROUP BY وHAVING: بين المنتجات المميّزة فقط، اربِط products بـcategories وأعِد كل department له منتجان مميّزان أو أكثر، مع ذلك العدد. استخدم العمودين department وfeatured_count.
