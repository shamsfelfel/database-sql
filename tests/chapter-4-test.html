Chapter 4 test

اختبار الفصل الرابع

Twenty questions of snowballing difficulty, drawn from all three databases — scalar, IN, correlated, EXISTS, derived tables, and subqueries in SELECT — ending in one combined statement. Each write-statement question is graded on the rows it returns, so any correct query passes.

عشرون سؤالًا تتصاعد صعوبتها، مأخوذة من القواعد الثلاث جميعها — القياسي، وIN، والمترابط، وEXISTS، والجداول المشتقة، والاستعلامات الفرعية في SELECT — وتنتهي بعبارة واحدة مركّبة. ويُصحَّح كل سؤال كتابة عبارة بناءً على الصفوف التي يُعيدها، فأيّ استعلام صحيح ينجح.

3write statement

Return the title of every course with credits above the average credits across all courses.

أعِد title كل مقرّر تكون creditsه أعلى من متوسط الساعات عبر كل المقررات.

5write statement

Return the name of every product that is NOT in any category belonging to the 'Home' department (use NOT IN).

أعِد name كل منتج لا ينتمي إلى أي فئة في قسم 'Home' (استخدم NOT IN).

7write statement

Return the title of every book priced above the average price of its own genre (correlated subquery).

أعِد title كل كتاب سعره أعلى من متوسط سعر نوعه genre (استعلام مترابط).

10write statement

Using EXISTS, return the name of every author who has written at least one book priced over 20.

باستخدام EXISTS، أعِد name كل مؤلف كتب كتابًا واحدًا على الأقل سعره أكثر من 20.

13write statement

Using a derived table, return each author's name alongside a column total_books holding their total number of books.

باستخدام جدول مشتق، أعِد name كل مؤلف مع عمود total_books يحوي إجمالي عدد كتبه.

15write statement

For each course, show its title and a column dept_avg_credits holding the average credits of courses in that course's department (correlated scalar subquery in SELECT).

لكل مقرّر، اعرض title وعمودًا dept_avg_credits يحوي متوسط ساعات مقررات قسم ذلك المقرّر (استعلام قياسي مترابط في SELECT).

17write statement

Using a derived table joined to categories, return the name of every category that has more than one product.

باستخدام جدول مشتق مربوط بـ categories، أعِد name كل فئة لديها أكثر من منتج واحد.

18write statement

Return the name of every department whose budget exceeds the average department budget. (A plain JOIN can't do this alone — "the average" isn't a row anywhere to join to.)

أعِد name كل قسم تتجاوز budgetه متوسط ميزانية الأقسام. (لا يستطيع JOIN وحده فعل ذلك — فـ"المتوسط" ليس صفًّا موجودًا لتربط به.)

19write statement

For each genre, return the title and genre of the most expensive book in that genre, using a correlated subquery (no GROUP BY).

لكل نوع، أعِد title وgenre أغلى كتاب في ذلك النوع، باستخدام استعلام مترابط (دون GROUP BY).

20write statement

Combining EXISTS, a JOIN, and a derived table in one statement, return the name of every category that (a) has at least one product priced above that category's average price, AND (b) has more than one product in total.

بجمع EXISTS وJOIN وجدول مشتق في عبارة واحدة، أعِد name كل فئة (أ) لديها منتج واحد على الأقل سعره أعلى من متوسط سعر تلك الفئة، و(ب) لديها أكثر من منتج واحد إجمالًا.
