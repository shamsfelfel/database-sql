Lesson 5 — Cross-table DELETE

الدرس ٥ — الحذف عبر الجداول

The same lookup pattern from lesson 4 works for DELETE: find the matching parent id(s) with a subquery into another table, then delete every child row that points at one of them.

نمط البحث نفسه من الدرس الرابع يعمل مع DELETE: اعثر على معرّف/معرّفات الأب المطابقة باستعلام فرعي يبحث في جدول آخر، ثم احذف كل صف ابن يشير إلى أحدها.

The same caution from earlier chapters still applies — always read the WHERE (subquery included) and be sure of what it actually matches before running the DELETE.

ويبقى التحذير نفسه من الفصول السابقة قائمًا — اقرأ دائمًا جملة WHERE (بما فيها الاستعلام الفرعي) وتأكّد ممّا تُطابقه فعليًّا قبل تشغيل DELETE.

Syntax pattern
نمط الصياغة
DELETE FROM child_table
WHERE parent_id_col IN (SELECT id FROM parent_table WHERE condition);

Worked examples — books and authors

أمثلة محلولة — books وauthors

Example 1 — remove one author's booksمثال ١ — حذف كتب مؤلف واحد
Example 2 — combine the lookup with an ordinary conditionمثال ٢ — الجمع بين البحث وشرط عادي
Example 3 — the danger case (shown, not run)مثال ٣ — حالة الخطر (معروضة، لا تُشغَّل)

The inner SELECT here returns every author's id — so the outer DELETE matches every book. A subquery that's too broad is exactly as dangerous as a missing WHERE.

يُرجع الاستعلام الداخلي SELECT هنا معرّف كل مؤلف — فيُطابق DELETE الخارجي كل كتاب. استعلامٌ فرعيٌّ واسعٌ أكثر من اللازم خطيرٌ تمامًا كجملة WHERE مفقودة.

The same pattern against Orbit Electronics — the products and categories tables.

النمط نفسه على Orbit Electronics — جدولا products وcategories.

Example 1 — delete overstocked Accessoriesمثال ١ — حذف منتجات Accessories ذات المخزون المرتفع
Example 2 — delete every Gaming productمثال ٢ — حذف كل منتجات فئة Gaming
Example 3 — the danger case (shown, not run)مثال ٣ — حالة الخطر (معروضة، لا تُشغَّل)

The inner SELECT returns every category's id — so this DELETE removes every product that has any category at all. Always check the subquery's scope before running it.

يُرجع الاستعلام الداخلي SELECT معرّف كل فئة — فيحذف هذا DELETE كل منتج له فئة أصلًا. تحقّق دائمًا من نطاق الاستعلام الفرعي قبل تشغيله.
