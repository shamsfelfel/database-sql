Lesson 2 — Scalar Subquery in WHERE

الدرس ٢ — استعلام فرعي قياسي في WHERE

A scalar subquery returns exactly one row and one column — a single value — usable anywhere a literal could go (=, >, <, >=, <=, <>).

الاستعلام الفرعي القياسي يُرجع صفًّا واحدًا وعمودًا واحدًا بالضبط — قيمة مفردة — يمكن استخدامها في أي موضع تصلح فيه قيمة حرفية (= و> و< و>= و<= و<>).

In a standard database, if it ever returns more than one row the query errors at runtime. Note that this course's in-browser engine is lenient and won't raise that error, but the shape is still wrong — keep scalar subqueries returning one value.

في قاعدة بيانات قياسية، إذا أرجع أكثر من صف واحد فسيُخفق الاستعلام أثناء التنفيذ. لاحظ أن محرّك هذه الدورة داخل المتصفح متساهل ولن يُطلق ذلك الخطأ، لكن الصياغة تظل خاطئة — أبقِ الاستعلامات الفرعية القياسية تُرجع قيمة واحدة.

Syntax pattern
نمط الصياغة
SELECT title, price FROM books WHERE price = (SELECT MAX(price) FROM books);

Worked examples — books and authors

أمثلة محلولة — books وauthors

A valid query that returns 0 rows — no book predates the oldest author's birth.استعلام صحيح يُرجع صفر صفوف — فلا يوجد كتاب أقدم من ميلاد أكبر المؤلفين سنًّا.

Example 3 — the danger case (shown, not run)مثال ٣ — حالة الخطر (معروضة، لا تُشغَّل)

GROUP BY makes this subquery return one row per category — more than one value. In a standard database a scalar = rejects that with an error; drop the GROUP BY to compare against the single overall average.

تجعل GROUP BY هذا الاستعلام الفرعي يُرجع صفًّا لكل فئة — أي أكثر من قيمة واحدة. في قاعدة بيانات قياسية يرفض المعامل القياسي = ذلك بخطأ؛ احذف GROUP BY للمقارنة مع المتوسط الإجمالي الواحد.
