Lesson 5 — DELETE

الدرس ٥ — الحذف (DELETE)

DELETE removes rows from a table. You state the table and a WHERE clause identifying which row(s) to remove. Just like UPDATE, a DELETE with no WHERE clause removes every row in the table — there's no separate "delete all" statement, so an accidentally-omitted WHERE is the single most common way to lose data by mistake. Always double-check the WHERE before running a DELETE.

تُزيل DELETE صفوفًا من الجدول. تذكر اسم الجدول وجملة WHERE تُحدِّد أي صف/صفوف تُزيلها. وتمامًا مثل UPDATE، فإن DELETE بلا WHERE تُزيل كل صف في الجدول — ولا توجد عبارة منفصلة لـ«حذف الكل»، لذا فإن نسيان WHERE سهوًا هو الطريقة الأكثر شيوعًا لفقدان البيانات بالخطأ. تحقّق دائمًا من WHERE قبل تشغيل DELETE.

Syntax pattern
نمط الصياغة
DELETE FROM table_name WHERE id = 1;
