Lesson 3 — Extremes (MIN, MAX)

الدرس ٣ — الطرفان (MIN و MAX)

MIN(column) returns the smallest value in a column and MAX(column) the largest. On numbers that's the lowest and highest; on text it's alphabetical order. Like the others, each returns one value and should be named with AS.

MIN(column) تُعيد أصغر قيمة في العمود، وMAX(column) أكبرها. على الأرقام هما الأدنى والأعلى، وعلى النصوص هما الترتيب الأبجدي. وكغيرهما، تُعيد كلٌّ منهما قيمة واحدة وينبغي تسميتها بـAS.

Several aggregates can share one SELECT. A single query can report the count, the average, the minimum and the maximum together — a compact "summary row" of a whole table.

يمكن لعدّة دوال تجميعية أن تتشارك في SELECT واحدة. فيستطيع استعلام واحد أن يذكر العدد والمتوسّط والحدّ الأدنى والحدّ الأعلى معًا — «صفّ ملخّص» مُوجَز للجدول كلّه.

Syntax pattern
نمط الصياغة
SELECT MIN(price) AS min_price, MAX(price) AS max_price FROM books;
