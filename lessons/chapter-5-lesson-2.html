Lesson 2 — Totals & Averages (SUM, AVG)

الدرس ٢ — المجاميع والمتوسّطات (SUM و AVG)

SUM(column) adds up the values in a numeric column; AVG(column) returns their mean. Both ignore NULL values and both return a single number, so — like COUNT — give the result a name with AS.

SUM(column) تجمع القيم في عمود عددي، وAVG(column) تُعيد متوسّطها. وكلاهما يتجاهل قيم NULL، وكلاهما يُعيد رقمًا واحدًا — فامنح الناتج اسمًا بـAS كما في COUNT.

An average often comes back with a long tail of decimals. Wrap it in ROUND(value, 2) to keep two decimal places — cleaner to read, and it makes the answer exact and predictable.

كثيرًا ما يعود المتوسّط بسلسلة طويلة من الكسور العشرية. لُفَّه بـROUND(value, 2) للإبقاء على منزلتين عشريتين — أوضح للقراءة، ويجعل الجواب دقيقًا ومتوقَّعًا.

Syntax pattern
نمط الصياغة
SELECT SUM(price) AS catalog_value FROM books;
SELECT ROUND(AVG(price), 2) AS avg_price FROM books;
