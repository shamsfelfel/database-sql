Lesson 4 — Grouping Rows (GROUP BY)

الدرس ٤ — تجميع الصفوف (GROUP BY)

So far an aggregate summarized the whole table into one row. GROUP BY splits the rows into groups that share a value, then computes the aggregate once per group — one summary row for each distinct genre, category, or level.

حتى الآن كانت الدالة التجميعية تُلخِّص الجدول كلّه في صفٍّ واحد. أمّا GROUP BY فتقسم الصفوف إلى مجموعات تتشارك قيمة، ثم تحسب التجميع مرّة لكل مجموعة — صفّ ملخّص واحد لكل نوع أو فئة أو مستوى مميّز.

The rule to remember: every column in the SELECT list is either grouped (named in GROUP BY) or aggregated (wrapped in COUNT/SUM/AVG/MIN/MAX). You can group by more than one column, and you can ORDER BY the aggregate to rank the groups.

القاعدة التي تُذكَر: كل عمود في قائمة SELECT إمّا مُجمَّع (مذكور في GROUP BY) أو مُجمَّع دالِّيًّا (داخل COUNT/SUM/AVG/MIN/MAX). ويمكنك التجميع حسب أكثر من عمود، وترتيب المجموعات بـORDER BY على قيمة التجميع.

Syntax pattern
نمط الصياغة
SELECT genre, COUNT(*) AS book_count
FROM books
GROUP BY genre
ORDER BY book_count DESC;

أمثلة محلولة — books

Swap the aggregate and the same groups yield a different summary.بدِّل الدالة التجميعية، فتُعطي المجموعات نفسها ملخّصًا مختلفًا.
Example 3 — rank the genres by countمثال ٣ — رتّب الأنواع حسب العدد
ORDER BY can sort by the aggregate's alias — biggest group first.تستطيع ORDER BY الترتيب حسب الاسم المستعار للتجميع — أكبر مجموعة أوّلًا.
