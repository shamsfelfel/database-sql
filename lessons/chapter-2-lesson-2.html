Lesson 2 — ALTER TABLE

الدرس ٢ — تعديل الجدول (ALTER TABLE)

A table's shape isn't fixed forever. ALTER TABLE ... ADD COLUMN adds a new column to an existing table — every existing row gets an empty/NULL value in it until you fill it in. ALTER TABLE ... DROP COLUMN removes a column entirely, along with whatever data it held for every row. There's no undo, so treat DROP COLUMN with the same care as a DELETE without a WHERE.

بنية الجدول ليست ثابتة إلى الأبد. تُضيف ALTER TABLE ... ADD COLUMN عمودًا جديدًا إلى جدول موجود — ويحصل كل صف موجود على قيمة فارغة/NULL فيه حتى تملأها. أما ALTER TABLE ... DROP COLUMN فتحذف العمود بالكامل مع كل ما حواه من بيانات في كل صف. ولا تراجُع عن ذلك، لذا عامل DROP COLUMN بالحذر ذاته الذي تعامل به DELETE بلا WHERE.

Syntax pattern
نمط الصياغة
ALTER TABLE table_name ADD COLUMN new_col TEXT;
ALTER TABLE table_name DROP COLUMN old_col;

Example 3 — drop the columnمثال ٣ — حذف العمود

ADD and DROP COLUMN let a table's shape evolve — but DROP COLUMN discards that column's data for every row, permanently.

تتيح ADD وDROP COLUMN لبنية الجدول أن تتطوّر — لكن DROP COLUMN تتخلّص من بيانات ذلك العمود في كل صف، وبشكل دائم.
