Lesson 1 — Types & Many Columns

الدرس ١ — الأنواع والأعمدة المتعددة

A column's type tells the database what kind of value the column holds, and it constrains what you can do with that value. This chapter uses four types: INTEGER (whole numbers), TEXT (strings), REAL (decimal numbers, for things like prices), and BOOLEAN (true/false). A single table can mix as many columns of as many types as it needs — you simply list them all, comma-separated, inside the CREATE TABLE parentheses. It's the same shape as chapter 1's two-column tables, just longer.

يُخبر نوع العمود قاعدةَ البيانات بنوع القيمة التي يحملها العمود، ويقيّد ما يمكنك فعله بتلك القيمة. يستخدم هذا الفصل أربعة أنواع: INTEGER (أعداد صحيحة)، وTEXT (نصوص)، وREAL (أعداد عشرية، لأشياء مثل الأسعار)، وBOOLEAN (صحيح/خطأ). ويمكن للجدول الواحد أن يمزج ما يشاء من الأعمدة بما تشاء من الأنواع — فقط تسردها جميعًا مفصولة بفواصل داخل قوسي CREATE TABLE. إنها البنية ذاتها لجداول الفصل الأول ذات العمودين، لكنها أطول فحسب.

Syntax pattern
نمط الصياغة
CREATE TABLE table_name (
  id INTEGER PRIMARY KEY,
  col_a TEXT,
  col_b REAL,
  col_c INTEGER,
  col_d BOOLEAN
);

Example 2 — CREATE TABLE IF NOT EXISTSمثال ٢ — CREATE TABLE IF NOT EXISTS

The safety habits from chapter 1 — IF NOT EXISTS, DROP TABLE IF EXISTS — still apply, no matter how many columns a table has. You can run this twice in a row without an error.

عادات الأمان من الفصل الأول — IF NOT EXISTS وDROP TABLE IF EXISTS — تبقى سارية مهما بلغ عدد أعمدة الجدول. يمكنك تشغيل هذه العبارة مرتين متتاليتين دون خطأ.

يأخذ كل عمود قيمةً، بالترتيب الذي سمّيتها به — قيمة REAL للسعر، وقيمة INTEGER للسنة، وtrue/false للعمود in_stock.
