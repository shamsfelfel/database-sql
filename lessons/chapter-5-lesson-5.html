Lesson 5 — Filtering Groups (HAVING)

الدرس ٥ — تصفية المجموعات (HAVING)

WHERE filters rows — and it runs before grouping, so it can't see a group's count or sum yet. To filter on the aggregate itself — "only groups with more than one book" — use HAVING, which runs after the groups are formed.

WHERE تُصفّي الصفوف — وتُنفَّذ قبل التجميع، فلا ترى بعدُ عدَّ المجموعة أو مجموعها. وللتصفية على قيمة التجميع نفسها — «المجموعات التي فيها أكثر من كتاب فقط» — استعمل HAVING التي تُنفَّذ بعد تكوين المجموعات.

A query can use both: WHERE trims the rows first, then GROUP BY forms groups, then HAVING keeps the groups you want, then ORDER BY ranks them. In HAVING you repeat the aggregate — HAVING COUNT(*) > 1, not the alias.

يمكن للاستعلام أن يستخدم الاثنين: تقلّم WHERE الصفوف أوّلًا، ثم تكوّن GROUP BY المجموعات، ثم تُبقي HAVING المجموعات المطلوبة، ثم ترتّبها ORDER BY. وفي HAVING تُكرّر الدالة التجميعية — HAVING COUNT(*) > 1، لا الاسم المستعار.

Syntax pattern
نمط الصياغة
SELECT genre, COUNT(*) AS book_count
FROM books
GROUP BY genre
HAVING COUNT(*) > 1;

WHERE vs HAVING. WHERE = a condition on each row, before grouping. HAVING = a condition on each group, after aggregating. Row conditions belong in WHERE; aggregate conditions belong in HAVING.

WHERE مقابل HAVING. WHERE = شرط على كل صف، قبل التجميع. HAVING = شرط على كل مجموعة، بعد التجميع. شروط الصفوف مكانها WHERE، وشروط التجميع مكانها HAVING.
