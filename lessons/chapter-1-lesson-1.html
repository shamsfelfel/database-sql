Lesson 1 — CREATE TABLE

الدرس ١ — إنشاء جدول (CREATE TABLE)

A table is where a database stores rows of the same shape — think of it like a single sheet in a spreadsheet, or an array of same-shaped objects in code. You define a table's shape once with CREATE TABLE: its name, and a list of columns, each with a type. The PRIMARY KEY marks the column that uniquely identifies each row — no two rows may share the same value there, and it can never be empty. In this lesson every table has just two columns: an id (a whole number, the primary key) and a name (text). Later chapters add more columns, more types, and relationships between tables — for now, keep it this simple on purpose.

الجدول هو المكان الذي تُخزِّن فيه قاعدة البيانات صفوفًا لها الشكل نفسه — تخيّله كورقة واحدة في جدول بيانات، أو كمصفوفة من كائنات متطابقة الشكل في الكود. تُعرّف شكل الجدول مرة واحدة باستخدام CREATE TABLE: اسمه، وقائمة بأعمدته، ولكل عمود نوع. ويُحدِّد PRIMARY KEY العمودَ الذي يُميّز كل صف بشكل فريد — لا يمكن لصفّين أن يتشاركا القيمة نفسها فيه، ولا يمكن أن يكون فارغًا أبدًا. في هذا الدرس يتكوّن كل جدول من عمودين فقط: id (عدد صحيح، وهو المفتاح الأساسي) وname (نص). ستضيف الفصول اللاحقة مزيدًا من الأعمدة والأنواع والعلاقات بين الجداول — أمّا الآن فنُبقيها بهذه البساطة عن قصد.

Syntax pattern
نمط الصياغة
CREATE TABLE table_name (
  id INTEGER PRIMARY KEY,
  name TEXT
);

Worked examples — the authors table

أمثلة محلولة — جدول authors

Example 1 — the basic statementمثال ١ — العبارة الأساسية

Creating a table just defines its shape. It starts out empty — the SELECT returns 0 rows.

إنشاء الجدول يُعرِّف شكله فقط. يبدأ فارغًا — لذا يُعيد SELECT صفرًا من الصفوف.

Example 2 — recreating safely with DROP TABLE IF EXISTSمثال ٢ — إعادة الإنشاء بأمان عبر DROP TABLE IF EXISTS

While experimenting, it's common to drop and recreate a table from scratch. IF EXISTS prevents an error on the DROP if it isn't there yet.

أثناء التجربة، من الشائع حذف الجدول وإعادة إنشائه من الصفر. تمنع IF EXISTS حدوث خطأ عند الحذف إذا لم يكن الجدول موجودًا بعد.

Example 3 — guarding the CREATE itselfمثال ٣ — حماية عبارة الإنشاء نفسها

IF NOT EXISTS is the CREATE-side guard — running this twice in a row never errors.

IF NOT EXISTS هي الحماية من جهة الإنشاء — تشغيلها مرتين متتاليتين لا يُسبِّب أي خطأ.
