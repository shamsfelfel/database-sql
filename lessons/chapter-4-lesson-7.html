Lesson 7 — Scalar Subquery in SELECT

الدرس ٧ — استعلام فرعي قياسي في SELECT

A scalar subquery can also sit in the SELECT list, adding a computed column alongside each row's own columns. It must still return exactly one value per row — one row, one column.

يمكن أن يوضَع الاستعلام الفرعي القياسي أيضًا داخل قائمة SELECT، فيضيف عمودًا محسوبًا إلى جانب أعمدة كل صف. ويجب أن يعيد قيمة واحدة بالضبط لكل صف — صف واحد وعمود واحد.

If the subquery is correlated (it references the outer row), that computed value differs from row to row. Never alias such a column avg, max, or min — those are reserved words and will cause a parse error; use descriptive names like overall_avg_price.

وإذا كان الاستعلام الفرعي مترابطًا (يشير إلى الصف الخارجي)، فإن القيمة المحسوبة تختلف من صف إلى آخر. ولا تُسمِّ مثل هذا العمود avg أو max أو min اختصارًا — فهي كلمات محجوزة تسبّب خطأ في التحليل؛ استخدم أسماء واضحة مثل overall_avg_price.

Syntax pattern
نمط الصياغة
SELECT title, price,
  (SELECT AVG(price) FROM books) AS overall_avg_price
FROM books;

Example 1 — attach the overall average price to every rowمثال ١ — إرفاق متوسّط السعر العام بكل صف

The subquery runs once; the same overall average is repeated next to every book.

يُنفَّذ الاستعلام الفرعي مرة واحدة؛ ويتكرّر المتوسّط العام نفسه بجانب كل كتاب.

Example 2 — each book's distance from the averageمثال ٢ — بُعد كل كتاب عن المتوسّط

You can compute with the returned value — here the row's own price minus the overall average.

يمكنك إجراء حساب على القيمة المُعادة — هنا سعر الصف نفسه price مطروحًا منه المتوسّط العام.

Example 3 — a correlated column: distance from the genre's averageمثال ٣ — عمود مترابط: البُعد عن متوسّط النوع

Because the subquery references b1.genre, it re-runs per row and the computed column differs for each genre.

ولأن الاستعلام الفرعي يشير إلى b1.genre، فإنه يُعاد تنفيذه لكل صف ويختلف العمود المحسوب باختلاف النوع.
