Lesson 2 — INSERT

الدرس ٢ — الإدراج (INSERT)

Once a table exists, INSERT adds rows to it. You state the table, the columns you're supplying values for (in parentheses), and the values themselves in the same order, wrapped in VALUES(...). Writing the column list explicitly — rather than relying on column order — is the safer habit: it keeps working even if the table's column order ever changes, and it makes the statement self-documenting. You can insert several rows in one statement by listing multiple VALUES groups separated by commas.

بعد أن يصبح الجدول موجودًا، تُضيف INSERT صفوفًا إليه. تذكر اسم الجدول، ثم الأعمدة التي ستزوّدها بقيم (بين قوسين)، ثم القيم نفسها بالترتيب ذاته داخل VALUES(...). وكتابة قائمة الأعمدة صراحةً — بدل الاعتماد على ترتيب الأعمدة — هي العادة الأكثر أمانًا: فهي تظل تعمل حتى لو تغيّر ترتيب أعمدة الجدول لاحقًا، وتجعل العبارة موثِّقة لنفسها. ويمكنك إدراج عدة صفوف في عبارة واحدة بسرد مجموعات VALUES متعددة مفصولة بفواصل.

Syntax pattern
نمط الصياغة
INSERT INTO table_name (id, name) VALUES (1, 'Some Name');
