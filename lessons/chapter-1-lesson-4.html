Lesson 4 — UPDATE

الدرس ٤ — التحديث (UPDATE)

UPDATE changes existing rows. You state the table, SET column = new_value for whichever column(s) you're changing, and a WHERE clause identifying which row(s). The WHERE clause is critical: an UPDATE with no WHERE clause changes every row in the table. Always double-check the WHERE before running an UPDATE.

تُغيّر UPDATE الصفوف الموجودة. تذكر اسم الجدول، ثم SET column = new_value للعمود/الأعمدة التي تُغيّرها، ثم جملة WHERE تُحدِّد أي صف/صفوف. وجملة WHERE بالغة الأهمية: فعبارة UPDATE بلا WHERE تُغيّر كل صف في الجدول. تحقّق دائمًا من WHERE قبل تشغيل UPDATE.

Syntax pattern
نمط الصياغة
UPDATE table_name SET name = 'New Name' WHERE id = 1;

WHERE can match on any column, not just the primary key — just be sure it's specific enough.

يمكن لـWHERE أن تطابق على أي عمود، لا المفتاح الأساسي فقط — فقط تأكّد أنها محدّدة بما يكفي.

Example 3 — the danger case (shown, not run)مثال ٣ — حالة الخطر (معروضة، لا تُشغَّل)

No WHERE clause means every row matches — this would rename every author to 'Anonymous'. Always check your WHERE clause before running an UPDATE.

غياب جملة WHERE يعني أن كل صف يطابق — وهذا سيُعيد تسمية كل مؤلف إلى 'Anonymous'. تحقّق دائمًا من جملة WHERE قبل تشغيل UPDATE.
