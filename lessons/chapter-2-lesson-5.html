Lesson 5 — Updating Many Columns

الدرس ٥ — تحديث أعمدة متعددة

A single UPDATE can change several columns in the same statement — list each column = new_value pair after SET, separated by commas. The WHERE clause still works exactly as in chapter 1: it decides which row(s) are touched, and omitting it updates every row.

يمكن لعبارة UPDATE واحدة أن تُغيّر عدة أعمدة في العبارة نفسها — اسرد كل زوج column = new_value بعد SET مفصولًا بفواصل. وتبقى جملة WHERE تعمل تمامًا كما في الفصل الأول: فهي تُحدِّد الصف/الصفوف المتأثرة، وحذفها يُحدِّث كل صف.

Syntax pattern
نمط الصياغة
UPDATE table_name SET col_a = value_a, col_b = value_b WHERE condition;
