Lesson 3 — Selecting Columns

الدرس ٣ — تحديد الأعمدة

Chapter 1 only ever selected * (everything) or a single column. Now that a table has more columns, you can name exactly the ones you want — comma-separated — in whatever order you'd like them to appear in the result. The order in the SELECT list does not have to match the table's column order, so you can present the same information more usefully for whoever's reading the result.

لم يكن الفصل الأول يحدد سوى * (كل شيء) أو عمودًا واحدًا. أما الآن وقد صار للجدول أعمدة أكثر، فيمكنك تسمية الأعمدة التي تريدها بالضبط — مفصولة بفواصل — بأي ترتيب تريد أن تظهر به في النتيجة. وترتيب قائمة SELECT ليس ملزَمًا بمطابقة ترتيب أعمدة الجدول، فبإمكانك عرض المعلومات نفسها بصورة أنفع لمن يقرأ النتيجة.

Syntax pattern
نمط الصياغة
SELECT col_a, col_b FROM table_name;
