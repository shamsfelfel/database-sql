Lesson 3 — Joining Tables (JOIN)

الدرس ٣ — ربط الجداول (JOIN)

JOIN lets one SELECT read matched data from two tables at once, following a foreign key from a child row to its parent row. You name both tables, and an ON clause saying how they match — the child's foreign key equals the parent's primary key. You can then select columns from either table in the same result. Give each table a short alias (e.g. b for books, a for authors) to keep column references short and unambiguous.

يتيح JOIN لعبارة SELECT واحدة قراءة بيانات متطابقة من جدولين معًا، متتبِّعًا مفتاحًا أجنبيًا من صف ابن إلى صف الأب. تذكر كلا الجدولين، وتكتب جملة ON تُبيّن كيف يتطابقان — المفتاح الأجنبي للابن يساوي المفتاح الأساسي للأب. عندها يمكنك اختيار أعمدة من أي من الجدولين في النتيجة نفسها. وأعطِ كل جدول اسمًا مختصرًا (alias) (مثل b لـbooks وa لـauthors) لإبقاء الإشارة إلى الأعمدة قصيرة وواضحة.

Syntax pattern
نمط الصياغة
SELECT b.title, a.name AS author_name
FROM books b
JOIN authors a ON b.author_id = a.id;
