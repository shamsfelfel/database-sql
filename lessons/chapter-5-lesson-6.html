Lesson 6 — Aggregation with JOIN

الدرس ٦ — التجميع مع JOIN

Grouping by an id like author_id works, but the result reads as numbers. JOIN the other table first and group by a readable column — the author's name, the category's department — and each summary row carries a label instead of a key.

التجميع حسب معرِّف مثل author_id يعمل، لكن الناتج يُقرأ أرقامًا. اربِط الجدول الآخر أوّلًا بـJOIN وجمِّع حسب عمود مقروء — اسم المؤلف name، أو قسم الفئة department — فيحمل كل صفّ ملخّص عنوانًا بدل مفتاح.

This is the whole chapter combined: JOIN two tables, keep some rows with WHERE, form groups with GROUP BY, summarize each with an aggregate, filter the groups with HAVING, and rank them with ORDER BY.

هذا هو الفصل كلّه مجتمعًا: اربِط جدولين بـJOIN، وأبقِ بعض الصفوف بـWHERE، وكوّن المجموعات بـGROUP BY، ولخّص كلًّا منها بدالة تجميعية، وصفِّ المجموعات بـHAVING، ورتّبها بـORDER BY.

Syntax pattern
نمط الصياغة
SELECT a.name AS author, COUNT(*) AS book_count
FROM authors a
JOIN books b ON b.author_id = a.id
GROUP BY a.name
ORDER BY book_count DESC;
