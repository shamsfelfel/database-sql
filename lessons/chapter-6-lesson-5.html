Lesson 5 — Building on Views

الدرس ٥ — البناء على العروض

A view is readable anywhere a table is readable — and that includes inside another view, inside a JOIN, and inside a subquery. So views are not just saved answers; they are building blocks you can stack.

العرض قابل للقراءة في كل موضع يكون الجدول فيه قابلًا للقراءة — وهذا يشمل داخل عرض آخر، وداخل JOIN، وداخل استعلام فرعي. فالعروض ليست أجوبة محفوظة فحسب؛ بل قوالب بناء يمكنك رصفها.

Three moves cover almost everything you will do:

ثلاث حركات تغطّي كل ما ستفعله تقريبًا:

  • A view on a view. Start from a broad view and narrow it: recent_books → recent_fiction. Each layer has one job and a name that says it.
  • A view in a JOIN. Treat the view as the left or right side of a join, exactly like a table.
  • A view in a subquery. Compare a row against a summary the view already computed — WHERE book_count = (SELECT MAX(book_count) FROM genre_stats).
  • عرضٌ على عرض. ابدأ من عرض واسع وضيّقه: recent_books ← recent_fiction. فلكل طبقة مهمّة واحدة واسم يقولها.
  • عرضٌ في JOIN. اعتبر العرض الطرف الأيسر أو الأيمن للربط، تمامًا كالجدول.
  • عرضٌ في استعلام فرعي. قارِن صفًّا بملخّصٍ حسبه العرض مسبقًا — WHERE book_count = (SELECT MAX(book_count) FROM genre_stats).

One caution worth carrying: layers are cheap to write and easy to over-build. Three thin, well-named layers are a gift to the next reader; eight are a maze. Add a layer when it has a meaning of its own, not merely because you can.

وتحذير جديرٌ بالحمل: الطبقات رخيصة الكتابة وسهلة الإفراط. فثلاث طبقات رقيقة حسنة التسمية هديّةٌ للقارئ التالي؛ وثمانٍ متاهة. أضِف طبقة حين يكون لها معنى خاصّ بها، لا لمجرّد أنك تستطيع.

Syntax pattern
نمط الصياغة
CREATE VIEW recent_fiction AS
SELECT title, price
FROM recent_books          -- a view, not a table
WHERE genre = 'Fiction';

4write statement

The joined view product_categories (product_id, product_name, price, category_name, department) exists. On top of it, create a view named home_products with the columns product_name and price, keeping only the Home department.

العرض المربوط product_categories (product_id وproduct_name وprice وcategory_name وdepartment) موجود. أنشئ فوقه عرضًا باسم home_products بالعمودين product_name وprice، مع الإبقاء على قسم Home فقط.

5write statement

The view available_products (id, name, price, category_id, stock_qty) exists. Join it to categories and return name and department for every available product priced above 1000. Use exactly those two column names.

العرض available_products (id وname وprice وcategory_id وstock_qty) موجود. اربِطه بـcategories وأعِد name وdepartment لكل منتج متوفّر سعره أعلى من ١٠٠٠. استخدم هذين الاسمين بالضبط.
