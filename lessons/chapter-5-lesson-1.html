Lesson 1 — Counting Rows (COUNT)

الدرس ١ — عدّ الصفوف (COUNT)

Every query so far returned rows one by one. An aggregate function collapses many rows into a single summary value. The simplest is COUNT — it answers "how many?".

كان كل استعلام حتى الآن يُعيد الصفوف صفًّا صفًّا. أمّا الدالة التجميعية فتطوي صفوفًا كثيرة في قيمة ملخِّصة واحدة. وأبسطها COUNT — تُجيب عن سؤال «كم العدد؟».

COUNT(*) counts rows. COUNT(column) counts rows where that column is not NULL. COUNT(DISTINCT column) counts the distinct non-null values. Because the result is one value, always give it a name with AS.

COUNT(*) تَعُدّ الصفوف. وCOUNT(column) تَعُدّ الصفوف التي لا تكون فيها قيمة العمود NULL. وCOUNT(DISTINCT column) تَعُدّ القيم المميّزة غير الفارغة. وبما أنّ الناتج قيمة واحدة، فامنحها اسمًا دائمًا بـAS.

Syntax pattern
نمط الصياغة
SELECT COUNT(*) AS book_count FROM books;
SELECT COUNT(DISTINCT genre) AS genre_count FROM books;

Don't name an aggregate result count, sum, avg, min or max — these are reserved words and the editor will reject the alias. Use a descriptive name like book_count.

لا تُسمِّ ناتج التجميع count أو sum أو avg أو min أو max — فهذه كلمات محجوزة سيرفضها المحرّر كاسم مستعار. استعمل اسمًا واصفًا مثل book_count.

Worked examples — books

أمثلة محلولة — books

Example 1 — how many books in allمثال ١ — كم عدد الكتب إجمالًا
One row, one column — the whole table folded into a single number.صفٌّ واحد وعمود واحد — الجدول كلّه مطويٌّ في رقم واحد.
Example 2 — count only the rows that match a filterمثال ٢ — عُدَّ الصفوف المطابقة للتصفية فقط
WHERE runs first and narrows the rows; COUNT then counts what's left.تُنفَّذ WHERE أوّلًا فتضيّق الصفوف، ثم تَعُدّ COUNT ما تبقّى.
Example 3 — how many distinct genresمثال ٣ — كم عدد الأنواع المميّزة
Ten books, but only four different genres. DISTINCT removes the repeats before counting.عشرة كتب، لكن أربعة أنواع مختلفة فقط. تُزيل DISTINCT المكرّرات قبل العدّ.
