Lesson 3 — SELECT

الدرس ٣ — الاستعلام (SELECT)

SELECT reads rows back out of a table. SELECT * FROM table_name; returns every column of every row. SELECT column_name FROM table_name; returns just that column. Adding WHERE column = value narrows it down to the row(s) matching that condition — with a primary key, that's exactly one row.

تقرأ SELECT الصفوف من الجدول. تُعيد SELECT * FROM table_name; كل عمود من كل صف. وتُعيد SELECT column_name FROM table_name; ذلك العمود فقط. وإضافة WHERE column = value تُضيّق النتيجة إلى الصف/الصفوف المطابقة لذلك الشرط — ومع مفتاح أساسي، يكون ذلك صفًا واحدًا بالضبط.

Syntax pattern
نمط الصياغة
SELECT * FROM table_name;
SELECT name FROM table_name;
SELECT * FROM table_name WHERE id = 3;
